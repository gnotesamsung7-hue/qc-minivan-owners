Get the app

Group code to join after installing

  1. Scan. Open the camera (or Google Lens) on the other phone, point it at the code, and tap the link that pops up.
  2. Download. The file QC-Minivan-Owners.apk downloads. If Chrome warns about the file, tap Download anyway.
  3. Install. Open the downloaded file. If Android asks, allow Install unknown apps for Chrome, go back, then tap Install.
  4. Join. Open the app, pick a callsign (not a real name), allow location and microphone, and join with the group code.

Android phones only. Updating? Install the new file over the old one; nothing is lost.

Before you join

  • The group sees your callsign, your live location and speed while the app is open, and hears you when you transmit.
  • You can pause location sharing anytime in the Me tab. When you leave a group, your location is deleted.
  • Voice clips are deleted from the server about 20 seconds after each transmission.
Driving? Don't hold the phone or press Talk while moving. Let a passenger handle the radio, or mount the phone and turn on hands-free voice mode. The Anti-Distracted Driving Act (RA 10913) fines start at ₱5,000.
